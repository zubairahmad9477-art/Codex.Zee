CSS BASICS

Learn CSS From Zero

CSS is used to style HTML pages and make websites attractive, responsive and easy to use.

What is CSS?

CSS stands for Cascading Style Sheets. It controls colors, fonts, spacing, layouts and many other visual parts of a website.

Your First CSS

body {
    font-family: Arial, sans-serif;
}

h1 {
    font-size: 40px;
}

p {
    line-height: 1.6;
}

What You Learned

You learned how CSS can change the appearance and layout of elements on an HTML page.

HTML BASICS

Learn HTML From Zero

HTML is the basic language used to create the structure of web pages.

What is HTML?

HTML stands for HyperText Markup Language. It is used to create headings, paragraphs, links, images, buttons and other elements on a webpage.

Your First HTML Page

<!DOCTYPE html>
<html>
<head>
    <title>My First Website</title>
</head>

<body>
    <h1>Hello World!</h1>
    <p>Welcome to my website.</p>
</body>
</html>

What You Learned

You learned the basic structure of an HTML page, including the html, head, title and body elements.
